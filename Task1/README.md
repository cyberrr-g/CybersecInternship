# Nmap Network Scan

## Overview

This task contains an **Nmap network scan** performed against a network IP address. The purpose of the scan is to identify available hosts, open ports, services, and other network information exposed by the target.

## Files

* `nmap-scan.html` — HTML report containing the results of the Nmap scan.

## Scan Report

Open `nmap-scan.html` in a web browser to view the complete scan results.

The report may contain information such as:

* Target IP address
* Host availability
* Open and closed ports
* Detected services
* Service versions
* Protocol information
* Nmap scan details

## Notes

The repository contains **only the Nmap HTML scan report**. No scripts, source code, or additional tools are included.

The scan results should only be used for systems and networks for which you have explicit authorization to perform security testing.
